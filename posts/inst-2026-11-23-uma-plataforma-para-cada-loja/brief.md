## Slide 2
```yaml
tipo: texto
titulo: Quando todo mundo divide o mesmo sistema
paragrafos:
  - Na maioria das plataformas, todas as lojas rodam no mesmo sistema. Isso tem um lado bom, pois uma melhoria chega para todo mundo de uma vez, sem você fazer nada.
  - O outro lado é que tudo anda no mesmo ritmo, e o que só a sua loja precisa espera caber no que serve para todas.
```

## Slide 3
```yaml
tipo: lista
titulo: Onde isso aparece no dia a dia
itens:
  - Um ajuste no checkout que só faz sentido para o seu público entra numa lista de pedidos
  - Uma mudança na integração com o ERP vale para todas as lojas ao mesmo tempo
  - Uma correção de segurança precisa servir para todas antes de chegar na sua
tema: claro
```

## Slide 4
```yaml
tipo: texto
titulo: Por que isso pesa na conversão
paragrafos:
  - As mudanças que mais mexem na conversão costumam ser as mais específicas, como o checkout do seu público e a página de produto do seu catálogo.
  - Por isso, quanto mais a loja cresce, mais caro fica esperar a plataforma decidir quando cada ajuste chega.
imagem: checkout-ui-mockup.jpg
```

## Slide 5
```yaml
tipo: lista
titulo: Como funciona na V2 da e-com.plus
itens:
  - Cada loja roda no próprio projeto do Google Cloud, com os apps que ela usa
  - A loja e as suas integrações podem ser atualizadas e customizadas sem esperar as outras
  - O que só a sua loja precisa é feito só para ela, no construtor de páginas ou no código
  - A frente de loja é código da marca, versionado no Git e com API aberta
tema: claro
```
